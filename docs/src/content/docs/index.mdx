## It's easy, and fun!™

Dependencies are ordinary functions and classes. Use `inject` to ask for one.

```ts
import { inject } from '@hypospray/core';

export function getStardate() {
  // Requires ES2264 or newer
  return () => StarDate.now();
}

export function createCaptainsLog(stardate = inject(getStardate)) {
  return (entry: string) => `Captain's log, stardate ${stardate()}. ${entry}`;
}
```

An injector resolves values and all of their dependencies.

```ts
import { createInjector } from '@hypospray/core';

const log = createInjector().get(createCaptainsLog);

log('We have arrived at Farpoint Station.');
// "Captain's log, stardate 41153.7. We have arrived at Farpoint Station."
```

## Control time

Pin the clock in a test by providing a fixed value.

```ts
import { createInjector, provideValue } from '@hypospray/core';

const log = createInjector({
  providers: [provideValue(getStardate, () => 47988.1)],
}).get(createCaptainsLog);

log('All good things must come to an end.');
// "Captain's log, stardate 47988.1. All good things must come to an end."
```

## Swap anything

Give each context its own version of a dependency.

```ts
import { createInjector, inject, provideFactory } from '@hypospray/core';

export function getMenu() {
  return ['Tea, Earl Grey, hot'];
}

export function createReplicator(menu = inject(getMenu)) {
  return (order: string) =>
    menu.includes(order) ? `Replicating: ${order}` : 'Unable to comply.';
}

const worfsQuarters = createInjector({
  providers: [provideFactory(getMenu, () => ['Gagh', 'Prune juice'])],
});

const replicate = worfsQuarters.get(createReplicator);

replicate('Prune juice'); // "Replicating: Prune juice"
replicate('Tea, Earl Grey, hot'); // "Unable to comply."
```

## Simulations within simulations

A child injector overrides its parent without affecting it.

```ts
import { createInjector, inject, provideValue } from '@hypospray/core';

export function getLocation() {
  return 'Deck 11, USS Enterprise';
}

export function describeSurroundings(location = inject(getLocation)) {
  return `You are in ${location}.`;
}

const ship = createInjector();

const holodeck = ship.createChild({
  providers: [
    describeSurroundings,
    provideValue(getLocation, 'Victorian London, 1890')
  ],
});

ship.get(describeSurroundings); // "You are in Deck 11, USS Enterprise."
holodeck.get(describeSurroundings); // "You are in Victorian London, 1890."
```

## Resistance is futile

`extendProvider` gives you access to the current value and lets you build on top of it.

```ts
import { createInjector, extendProvider } from '@hypospray/core';

export class CrewMember {
  constructor(
    public name: string,
    public rank: string,
  ) {}
}

export function getCrew() {
  return [
    new CrewMember('Jean-Luc Picard', 'Captain'),
    new CrewMember('William Riker', 'Commander'),
  ];
}

const cube = createInjector({
  providers: [
    extendProvider(getCrew, (crew) => {
      const [captain] = crew;

      // Add his uniquenss to our own...
      const locutus = { ...captain, name: 'Locutus', rank: 'Drone' };

      return [locutus];
    }),
  ],
});

cube.get(getCrew).map((member) => member.name);
// ["Locutus"]
```

## Highlights

* Use plain functions and classes, no need for decorators or tokens.
* Framework agnostic (but it's pretty sure they exist).

## Features

* Hierarchical injectors
* Use functions, or classes, or both! (or neither)
* Adapters for common frameworks
* Easily override dependencies
* Type-safe by default
