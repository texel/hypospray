## Small enough to explain

```ts
import { createInjector, inject } from '@hypospray/core';

const createClock = () => ({ now: () => Date.now() });

const createGreeter = (clock = inject(createClock)) => ({
  greet: (name: string) => `Hello, ${name}. It is ${clock.now()}.`,
});

const injector = createInjector();
const greeter = injector.get(createGreeter);
```

No decorators. No reflection metadata. No framework required.
